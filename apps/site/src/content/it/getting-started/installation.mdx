# Installazione

Quattro passi: il pacchetto, il foglio di stile, il provider, il primo componente.

## Con Vite e React

### 1. Installa il pacchetto

```bash title="Terminale"
npm install @slurp-ui/react
```

`@slurp-ui/react` include i token, le icone (`@slurp-ui/react/icons`) e il motore dell'animazione: non serve installarli a parte. Con pnpm o yarn: `pnpm add @slurp-ui/react`, `yarn add @slurp-ui/react`.

### 2. Importa il foglio di stile

Una volta, alla radice dell'app. Contiene i token `--slurp-*`, il font Poppins e gli stili di tutti i componenti, dentro `@layer slurp.*`: i tuoi CSS vincono senza `!important`.

```tsx title="main.tsx"
import '@slurp-ui/react/styles.css';
```

### 3. Avvolgi l'app nel provider

`SlurpProvider` porta il tema, la scelta chiaro / scuro, i testi dei componenti e il registro dell'animazione. `Ground` applica lo sfondo e la tipografia di base.

```tsx title="App.tsx"
import { createTheme, Ground, SlurpProvider } from '@slurp-ui/react';

const theme = createTheme({ accent: 'hue-violet' });

export function App() {
  return (
    <SlurpProvider theme={theme} labels="it">
      <Ground />
      {/* la tua app */}
    </SlurpProvider>
  );
}
```

### 4. Usa i componenti

```tsx title="Salva.tsx"
import { Button } from '@slurp-ui/react';

export function Salva() {
  return <Button>Salva</Button>;
}
```

## Requisiti

- **React 19** o successivo (`react` e `react-dom` sono peer dependency).
- **Solo ESM**: funziona con Vite, Next.js, React Router e ogni bundler moderno.
- Browser: le ultime due versioni dei browser evergreen e Safari 17+.

## Import per componente

Ogni componente ha anche il suo subpath, utile per caricare solo ciò che serve:

```tsx title="App.tsx"
import { Button } from '@slurp-ui/react/Button';
import { useSlurp } from '@slurp-ui/react/motion';
```

<Callout title="Rendering lato server">
  Con Next.js o un altro rendering lato server aggiungi `<ColorSchemeScript />` nel `<head>`, così il tema scelto è applicato prima del primo paint. Vedi [Vite, Next.js e router](/getting-started/frameworks).
</Callout>
