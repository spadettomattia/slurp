# Cell

Il mattone di base: qualunque elemento, stilizzato con `css`. Serve quando nessun altro componente è abbastanza semplice.

## Esempi

### Un elemento a piacere

`as` sceglie il tag; `css` accetta le proprietà CSS con i token (`var(--slurp-…)`), scritte come in un oggetto.

## Accessibilità

- Rende l’elemento che scegli con `as`: scegli quello giusto per il significato (`section`, `nav`, `ul`…).
- Non aggiunge ruoli né testi.
