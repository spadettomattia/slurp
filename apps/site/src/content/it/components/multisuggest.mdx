# MultiSuggest

Suggest per più scelte: la lista resta aperta mentre scegli e ogni scelta diventa un tag che si toglie.

## Esempi

### Più colori

`value` è l’elenco dei valori scelti, nell’ordine di scelta. Backspace nel campo vuoto toglie l’ultimo; con `name` si invia un campo nascosto per valore.

## Accessibilità

- Un `combobox` con elenco `aria-multiselectable`: frecce per muoversi, Invio per scegliere o togliere.
- Ogni scelta è un bottone “Rimuovi …” in una lista con nome.
- Il numero di suggerimenti è annunciato in una regione `status`.
