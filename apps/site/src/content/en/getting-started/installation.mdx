# Installation

Four steps: the package, the stylesheet, the provider, the first component.

## With Vite and React

### 1. Install the package

```bash title="Terminal"
npm install @slurp-ui/react
```

`@slurp-ui/react` includes the tokens, the icons (`@slurp-ui/react/icons`) and the motion engine: no need to install them separately. With pnpm or yarn: `pnpm add @slurp-ui/react`, `yarn add @slurp-ui/react`.

### 2. Import the stylesheet

Once, at the root of the app. It holds the `--slurp-*` tokens, the Poppins font and every component's styles, inside `@layer slurp.*`: your own CSS wins without `!important`.

```tsx title="main.tsx"
import '@slurp-ui/react/styles.css';
```

### 3. Wrap the app in the provider

`SlurpProvider` carries the theme, the light / dark choice, the components' texts and the motion registry. `Ground` applies the background and the base typography.

```tsx title="App.tsx"
import { createTheme, Ground, SlurpProvider } from '@slurp-ui/react';

const theme = createTheme({ accent: 'hue-violet' });

export function App() {
  return (
    <SlurpProvider theme={theme} labels="en">
      <Ground />
      {/* your app */}
    </SlurpProvider>
  );
}
```

### 4. Use the components

```tsx title="Save.tsx"
import { Button } from '@slurp-ui/react';

export function Save() {
  return <Button>Save</Button>;
}
```

## Requirements

- **React 19** or later (`react` and `react-dom` are peer dependencies).
- **ESM only**: works with Vite, Next.js, React Router and every modern bundler.
- Browsers: the last two versions of evergreen browsers and Safari 17+.

## Per-component imports

Every component also has its own subpath, to load only what you use:

```tsx title="App.tsx"
import { Button } from '@slurp-ui/react/Button';
import { useSlurp } from '@slurp-ui/react/motion';
```

<Callout title="Server rendering">
  With Next.js or any server rendering add `<ColorSchemeScript />` to the `<head>`, so the chosen theme applies before the first paint. See [Vite, Next.js and routers](/getting-started/frameworks).
</Callout>
