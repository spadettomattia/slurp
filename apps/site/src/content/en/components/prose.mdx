# Prose

Long text that arrives as HTML (Markdown, MDX, a CMS) takes the system's typography with no hand-written classes.

### Basic use

Wrap the content: headings, paragraphs, lists, quotes, tables, code and images take the system's scale and spacing, in a reading measure of about 70 characters. Components placed inside keep their own styles.

## Accessibility

- It leaves the structure as it is: headings stay headings, lists stay lists.
- Links are underlined and `accent-ink`: recognisable without colour.
