## Accessibility

- As an input it is a `fieldset` with a visible legend and a radio per star (“3 stelle”): arrows move and choose.
- Chosen stars are filled (`accent-ink`), the others only outlined (`border-control`, 3:1): shape, not only colour. Each star is a 44px target.
- Read-only it is an image with the value in words (“Media: 4.5 su 5”); the texts are in `labels`.
