# ErrorSummary

The list of a form’s errors, at the top: it announces the problem, takes focus and leads to each field with a link.

### After submitting

## Accessibility

- It is a `role="alert"`: it appears and is read at once; it takes focus to bring attention there.
- Each error is a link to the field’s `id`: it reaches it and focuses it.
- With no errors it renders nothing.
