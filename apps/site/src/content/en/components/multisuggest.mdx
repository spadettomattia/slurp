# MultiSuggest

Suggest for several choices: the list stays open while you pick and each choice becomes a tag you can remove.

## Examples

### Several colours

`value` is the list of chosen values, in the order chosen. Backspace in an empty field removes the last one; with `name` one hidden field per value is submitted.

## Accessibility

- A `combobox` with an `aria-multiselectable` list: arrows to move, Enter to choose or remove.
- Each choice is a “Remove …” button in a named list.
- The number of suggestions is announced in a `status` region.
