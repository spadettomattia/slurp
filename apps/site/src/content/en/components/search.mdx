## Accessibility

- It sits in a `search` landmark; the field has a name (`labels.label`, “Cerca”) besides the placeholder.
- `count` is announced politely (`labels.results`) while typing.
- With several searches on one page give each one a name (`aria-label` on the root), so the landmarks can be told apart.
- The clear button has a name (`labels.clear`) and puts focus back in the field; Enter calls `onSearch`.
