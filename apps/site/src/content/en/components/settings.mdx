## Accessibility

- A named round button that becomes the panel: Bloom’s rules apply (focus into the panel, Escape back to the button).
- Theme and Language are named radio groups, as rows with icon and check.
- Each language is written in itself and has its own `lang`: the screen reader pronounces it well.
