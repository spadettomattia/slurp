# Slurp UI

Libreria React del design system Slurp: componenti pronti, personalizzazione per istanza e, su richiesta, la transizione collapse / expand.

```bash
npm i @slurp-ui/react
```

```tsx
import '@slurp-ui/react/styles.css';
import { createTheme, Ground, SlurpProvider, Text } from '@slurp-ui/react';

const theme = createTheme({ accent: 'hue-teal', tokens: { radius: { card: 30 } } });

export function App() {
  return (
    <SlurpProvider theme={theme}>
      <Ground />
      <Text font="display-xl">Di cosa hai bisogno?</Text>
    </SlurpProvider>
  );
}
```

## Contenuto

- Token del design system come CSS custom properties `--slurp-*` (chiaro e scuro) e costanti TypeScript.
- Sistema: `createTheme`, `SlurpProvider`, `useColorScheme`, `AccentScope` / `vivid()`, prop `css`.
- Fondamenta: `Ground`, `Cell`, `Flow`, `Frame`, `Text`, `Surface`.
- Componenti: `Button`, `Bubble`, `Chip`, `Segmented`, `Count`, `Avatar`, `Swatch`, `Field`, `Search`, `Choice`, `Checkbox`, `Radio`, `Switch`, `Range`, `Tabs`, `Fold`, `Notice`, `Hint`, `Bloom`, `Menu`, `Dialog`, `Sheet`, `Toast`, `Progress`, `Placeholder`.
- Comportamenti condivisi (`@slurp-ui/react/utils`): `useDismiss`, `focusFirst`, `moveFocus`, `useRovingFocus`, `useControlled`, `useMediaQuery`.
- Animazione (opzionale): `useSlurp`, `AnimationGroup` e le props `animation*` di ogni componente; il motore è in `@slurp-ui/react/motion`.

## Personalizzare

Tre livelli, dal più globale al più locale:

1. **Tema** — `createTheme({ accent, tokens, components })`: accento, override dei token, default e `css` per componente.
2. **Prop `css`** — token (`p: 4`, `bg: 'accent-soft'`, `radius: 'card'`, `font: 'title-l'`), selettori (`'&:hover'`), breakpoint (`{ base, compact, wide }`).
3. **Variabili CSS** — `style={{ '--slurp-surface-radius': '12px' }}`, senza runtime.

Gli stili stanno in `@layer slurp.reset, slurp.base, slurp.components, slurp.utilities`: i CSS del consumer vincono senza `!important`.

## Animazione

La transizione collapse / expand è opzionale: i componenti si limitano a registrarsi con `animationId` (e `animationGroup`), l'avvio è sempre di `useSlurp()`.

```tsx
const { collapse, expand } = useSlurp();

<AnimationGroup id="tiles">
  {sections.map((s) => (
    <Cell key={s.id} animationId={`tile-${s.id}`} onClick={() => open(s)} />
  ))}
</AnimationGroup>;

// n → 1 per andare avanti: le tile si fondono nel crumb, la scelta per ultima.
await collapse({ items: { group: 'tiles' }, target: 'crumb', lead: `tile-${s.id}` }).finished;
// 1 → n per tornare indietro.
expand({ source: 'crumb', items: { group: 'tiles' } });
```

Con `prefers-reduced-motion` diventa una dissolvenza di 150 ms. I default (durata, sfalsamento, goo, ghost…) stanno in `createTheme({ motion })`.

## Pannelli: il bottone diventa il pannello

Nessun popover compare accanto al bottone: con `Bloom` (e `Choice`, `Menu` che ci sono costruiti sopra) la superficie del bottone cresce in larghezza, altezza e raggio fino a diventare il pannello, e torna bottone quando si chiude. Click fuori, Escape o Tab chiudono; Escape riporta il focus sul bottone.

## Tema chiaro e scuro

`data-theme="light"` o `data-theme="dark"` su `<html>` (o su un sottoalbero) vince sempre su `prefers-color-scheme`. `useColorScheme()` restituisce `{ mode, setMode, resolved }` e ricorda la scelta. Con il rendering lato server, `<ColorSchemeScript />` in `<head>` applica la scelta prima del primo paint.
